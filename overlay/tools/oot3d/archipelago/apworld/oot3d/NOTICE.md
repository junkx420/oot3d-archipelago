# Third-party code and data in this world

- **Ship of Harkinian apworld** (HarbourMasters/Archipelago-SoH, revision
  84c059f2): the world's structure, logic and options, adapted to the
  3DS game. MIT License, see `LICENSE`.
- **OoT3D_Randomizer** (gamestabled/OoT3D_Randomizer, revision ae0fcf56):
  location and item tables (scenes, flags, get-item ids) were generated from
  its sources, and its logic was the reference for the 3D rule changes. Its
  license text, which carries OoT-Randomizer's MIT License, is in
  `LICENSE-OoT3D_Randomizer.md`.

No game code, ROM data or assets are part of this world.
