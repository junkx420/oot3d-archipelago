Fifth alpha. `TriAevum-Archipelago-v0.1.0-alpha.5-Windows-x64.zip` replaces
`TriAevum.exe` in a Forge-prepared TriAevum v0.8.0-beta.1.2 (Windows, EUR);
see `README-ARCHIPELAGO.txt` in it. `oot3d.apworld` world version 0.6.0, for
Archipelago 0.6.7 or newer (generated on 0.6.8). SHA-256
`ee317467a9c09fd5aa6154477d6d2e955772033b618ba3f3ab24d9f6115947dd`.
Update both together.

## New

- **Skip cutscenes** now skips every dungeon's blue warp cutscene: Link goes
  straight to the entrance or warp pad, and the reward comes from the
  server (Jabu-Jabu's sapphire from the game).
- Options: closed forest "deku only" and "off", Kakariko gate open (the mask
  shop opens right away too), Door of Time open.

## Fixed

- The Great Fairy rewards and the Light Arrow cutscene are checks: the
  fairy's own spell or upgrade, or the Light Arrows, no longer stay in your
  game when the location holds another item; that item comes from the
  server.
- A received item could count as a location (a Fairy Ocarina from the
  starting inventory as Saria's gift).

Tested headless: the dev build and the release exe in a copy of a
Forge-prepared beta.1.2 installation; the client's hooks verified against
the running code and a seed with the new options set its flags. Not yet
seen in the game: the warp skips, the fairies and the forest exit.
