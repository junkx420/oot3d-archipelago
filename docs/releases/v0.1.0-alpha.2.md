Second alpha. `oot3d.apworld` world version 0.4.0, for Archipelago 0.6.7 or
newer (tested on 0.6.8 and 0.6.9). SHA-256
`00c4360487a0a64eb18943346b73a6bb7d593ce574aa1cc54af485aa856733d0`.

## New

- Quick text (F1 > Game > Archipelago > Text boxes): instant text boxes, and
  holding B (the sword button) advances and closes them.
- Received items survive reloads, savestates and new files.
- Options Creator: only the options the client supports are shown.
- The apworld manifest carries `version` and `compatible_version`.

## Install

Archipelago launcher: **Install APWorld** with `oot3d.apworld`, or copy it
into `custom_worlds`. The game side is source only (`docs/BUILD.md`).

Known limits as in v0.1.0-alpha.1; pots, crates, grass and similar are not
locations yet.
