First alpha of Archipelago multiworld support for TriAevum, the native
recompilation of *The Legend of Zelda: Ocarina of Time 3D*.

## Download

- `oot3d.apworld` (world version 0.3.0): put it into the Archipelago
  launcher's `custom_worlds` folder to generate and host seeds and to use
  Universal Tracker. Needs Archipelago 0.6.7 or newer. SHA-256
  `81ee33640c692612ef9a8bf52566e744313b40b22395979fafda03a3cd5cc691`.
- The game side is source only: apply this repository to TriAevum with
  `tools/setup.ps1`, build with `-DTRIAEVUM_ENABLE_ARCHIPELAGO=ON`
  (`docs/BUILD.md`) and use your own EUR ROM. No game build is attached: it
  would contain code compiled from the ROM.

## What works

- Checks from the game's own item locations (chests, NPC gifts, heart
  pieces and similar), with dungeon keys, maps and compasses in their own
  dungeon or vanilla.
- Multiworld items at those locations: your own items that the game has a
  get-item for show their real model; other players' items and your keys,
  songs and magic show a placeholder and arrive through the server, other
  players' with an in-game message naming them.
- Received items given in the game with the normal get-item; the server is
  the only item source, so a new file receives everything again.
- Goal (leaving Ganon's battle alive), DeathLink, optional cutscene skips
  that change nothing in the logic.
- Enable switch in F1 > Game > Archipelago, auto-connect at start, automatic
  reconnect, in-game messages, Archipelago badge on the title and file
  selection.
- Universal Tracker: rebuilds the world from slot data, shows the 3D logic.

## Known limits

- Only the options the client supports can be generated; shuffles beyond the
  game's own locations (tokens, songs, shops, scrubs, ...) and 3D tricks are
  not there yet.
- Other games' items show a recovery heart at their location.
- Not yet tried in the game: Skulltula tokens, freestanding items, songs, the
  goal at Ganon, reloading a save after receiving.
- Tested only on the developer build on Windows.
- Details: `overlay/docs/archipelago/KNOWN_ISSUES.md`.
