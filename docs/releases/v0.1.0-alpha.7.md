## New

- Cow shuffle: play Epona's Song to a cow; it gives its location's item
  without needing an empty bottle, then milk as usual.
- Shop shuffle (with how many items per shop are shuffled): a shuffled slot
  sells its location's item at the seed's price, once, then shows sold out.
  The shelf still shows the game's own item and text, so read the in-game
  message after buying to see what you got.

Tested headless with a seed shuffling shops and cows (313 locations): the
dev build and the release exe in a copy of a Forge-prepared beta.1.2
installation connect and scout it, with the client's hooks verified against
the running code. Not yet seen in the game: a cow or a shop purchase; please
report what happens.
