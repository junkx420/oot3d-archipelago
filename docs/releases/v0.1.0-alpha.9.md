Ninth alpha: logical tricks. `oot3d.apworld` world version 0.10.0, for
Archipelago 0.6.7 or newer. SHA-256
`b5bb5ca7496b03a84c6a18edfbca1393218f16103d4674a77ba80a2c0327d7a1`.
`TriAevum-Archipelago-v0.1.0-alpha.9-Windows-x64.zip` holds the same
`TriAevum.exe` as alpha.8 (the client did not change); see
`README-ARCHIPELAGO.txt` in it.

## New

- **Tricks in Logic**: 33 tricks, chosen by their OoT3D Randomizer names
  (for example "DT B1 Navigation w/o Slingshot", "Haunted Wasteland w/o Lens
  of Truth"). Each one was compared with the 3D randomizer's own logic: with
  it on, the logic never expects more than the 3D randomizer does.
  "Enable All Tricks" turns all of them on.

## Fixed

- With Gold Skulltula tokens shuffled, the Deku Tree basement vines token
  was in logic with only a jump slash; it now needs a projectile, Din's Fire
  or the new trick "DT B1 Vines GS w/ Jump Slash", as in the 3D randomizer.

Glitched logic is not part of this release.
