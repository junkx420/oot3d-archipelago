First release out of alpha. `oot3d.apworld` world version 0.11.2, for
Archipelago 0.6.7 or newer (the logic is the same as in alpha.10 and
alpha.11; seeds are the same). SHA-256
`83a4caafe73823b7eea86e3a70778ffb82f7611c74a5084471ec2a97fee98e15`.
`TriAevum-Archipelago-v0.1.0-Windows-x64.zip` holds a new `TriAevum.exe` for
an installed TriAevum v0.8.0-beta.1.2; see `README-ARCHIPELAGO.txt` in it.

Everything the alphas brought is here: checks and multiworld items, the
received items, the goal, DeathLink, the world options, shuffles, tricks and
glitched logic, cutscene skips and the client options of alpha.11 (cheats,
fast chests, song replay skip, damage multiplier).

## New since alpha.11

- **Another player's item says what it is.** A location that holds another
  player's item still shows a recovery heart, but its text box now reads
  "You found *Hookshot* for *Alice*!", with the item in red and the player
  in blue. The same for this world's items the game has no get-item for
  (for example dungeon keys): "You found *Forest Temple Small Key*!". It
  works through the client's hooks; no game code is patched.
- **Names in messages.** Messages no longer say "an item" or "another
  player" when the server's data package arrived after the location scouts.
- **Remember password** (F1 > Game > Archipelago, off by default): the
  password is saved with the server and slot, so auto-connect works with a
  passworded room. It is kept as plain text in `archipelago.json`; turning
  the option off removes it.
- The setup guide describes the release package (it still said the game must
  be built from source).

## Checked

- The item text was seen in the game, connected to a local server, with a
  real seed's names.
- `wss://`: the certificate check passes against archipelago.gg.
- The new `TriAevum.exe` was started in a copy of an installed TriAevum: all
  of the client's hooks matched the game's code.

## Known

- Fast chests, the song replay skip and the damage multiplier (all off by
  default) were not yet tried on a chest, a song or a hit in the game, nor
  was the item text opened on a real chest; a whole session on a room hosted
  on archipelago.gg was not tried either.
- Not supported yet: song and dungeon reward shuffles, Master Quest,
  entrance shuffle, models for other games' items.
- The full list is in `KNOWN_ISSUES.md`.
