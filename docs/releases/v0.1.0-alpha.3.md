Bug-fix alpha. Game side only; `oot3d.apworld` is unchanged from
v0.1.0-alpha.2 (world version 0.4.0, SHA-256
`00c4360487a0a64eb18943346b73a6bb7d593ce574aa1cc54af485aa856733d0`).

## Fixed

- The game crashed with "guest memory regions overlap" when leaving Kokiri
  Forest (Lost Woods, the Deku Tree, the way to the sword chest). The
  client's memory page sat where TriAevum maps extra object slots for
  scenes with many objects; it moved, and the build now checks at compile
  time that it collides with nothing.

## Upgrade

Rebuild the game from this source (`docs/BUILD.md`). Do not load
savestates made with v0.1.0-alpha.2 or older; load the in-game save
instead. Seeds, saves and progress files carry over.
