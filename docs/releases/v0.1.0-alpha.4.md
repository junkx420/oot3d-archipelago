Fourth alpha with new options. `oot3d.apworld` world version 0.5.0, for
Archipelago 0.6.7 or newer (generated on 0.6.8). SHA-256
`795ae189b09c628c0355ecd9ef4e3eaa1a2e418e9641d448ab9444c569dcc483`.
First release with a game executable:
`TriAevum-Archipelago-v0.1.0-alpha.4-Windows-x64.zip` holds a replacement
`TriAevum.exe` for TriAevum v0.8.0-beta.1.2 (Windows), prepared by Forge from
your own EUR ROM. It holds TriAevum's runtime with the Archipelago client;
the game code stays in TriAevum's own title module. Install: back up
`TriAevum.exe` in the TriAevum folder and copy the package over it
(`README-ARCHIPELAGO.txt`). Update the apworld together with it.

Tested on Windows in a copy of a Forge-prepared beta.1.2 installation:
the client verified its hooks against TriAevum's title module, connected,
set the seed's world settings and gave the starting items in the game.

## New

- Options: Zora's Fountain open, Jabu-Jabu open, rainbow bridge always
  open, Ganon's trials (skip, or 0 to 6), and starting with the Kokiri
  Sword, a Deku Shield, an ocarina or magic beans (sent by the server at
  the start).
- **Skip cutscenes** (F1 > Game > Archipelago), with a connected save, also
  skips the Deku Tree's and Dodongo's Cavern's blue warp cutscenes: Link
  warps straight back, and the stone comes from the server.

## Fixed

- Checks that never reached the server: Queen Gohma's and the other bosses'
  rewards, Saria's gift on the Lost Woods bridge, Zelda's Letter.
- A Gold Skulltula token next to a chest could report that chest early.

Not supported yet: open forest, Kakariko gate, Door of Time, Gerudo
Fortress carpenters, Jabu-Jabu's and the adult dungeons' warp cutscenes.
